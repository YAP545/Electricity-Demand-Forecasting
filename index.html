Electricity Demand Forecasting using Deep Learning

This project compares RNN, CNN, LSTM, and TCN models for short-term electricity demand forecasting.

Results

Model RMSE MAE
LSTM 0.01581 0.01163
RNN 0.01614 0.01211
TCN 0.01684 0.01230
CNN 0.01716 0.01283

Best Model

LSTM achieved the best performance with the lowest RMSE and MAE.
